BIMTech Revit 2024 Addin installer

Install target:
- Current user only
- %LocalAppData%\BIMTechTool\Revit2024Addin\BIMTech Tool.extension
- %AppData%\Autodesk\Revit\Addins\2024\BIMTech Tool.addin

How to install:
1. Close Revit 2024.
2. Run BIMTech_Revit2024_Installer.exe.
3. Open Revit 2024 and check tab BIMTech.

This installer does not require admin rights.

GitHub release upload files:
- BIMTech_Revit2024_Installer.exe
- manifest.json
- BIMTechTool-Revit2024.zip
